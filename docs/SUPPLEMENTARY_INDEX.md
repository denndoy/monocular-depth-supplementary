The MP4s are visual demonstrations. Quantitative distance metrics are evaluated at marker-crossing events, not continuously per frame. For display only, avatar depth is anchored at selected marker-crossing frame/GT pairs and interpolated between anchors. This path is not quartic output or a metric; distance metrics use raw quartic predictions at crossing events. Depth is compressed and lateral position is schematic.
