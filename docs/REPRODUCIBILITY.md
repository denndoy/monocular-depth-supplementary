# Reproducibility limits

The released CSVs allow recalculation of headline marker-event metrics with `scripts/verify_supplementary_metrics.py` and Python's standard library. The verifier does not train models, access the network, or write files.

This repository does not include original participant videos, detector/classifier checkpoints, private annotation sources, complete job directories, or environment-specific pipeline inputs. It cannot reproduce YOLO detection, ByteTrack tracking, participant mapping, automatic event selection, or end-to-end frame-wise inference. Mapping accuracy and candidate-selection sensitivity were not independently evaluated. Full end-to-end reproduction is therefore not claimed.

CSV records use study-specific class/category IDs and frame indices without participant names. The repository includes face-blurred demo videos and privacy-processed field photographs for qualitative illustration; it does not release raw detector/classifier training sources or support full end-to-end reproduction. The researcher reports oral participant/guardian consent for public sharing and redistribution with facial blur maintained; no independent consent-document inspection or frame-by-frame privacy check occurred. See `../MEDIA_SHARING.md`. Prior Git commits contained AI-selected CC BY 4.0 text, whose removal from the active tree does not automatically revoke historical licenses.
