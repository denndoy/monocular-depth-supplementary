# Supplementary figures (Rev6)

The six PNGs in this directory match the figure order in the Rev6 manuscript:

1. `Fig_1_Workflow.png` - high-level research pipeline.
2. `Fig_2_Marker_Measurement.png` - field documentation of marker measurement.
3. `Fig_3_Experimental_Layout.png` - schematic of camera, lane, and markers.
4. `Fig_4_Detailed_Research_Pipeline.png` - detailed A-I flowchart.
5. `Fig_5_Personal_Quartic_Curves.png` - four fitted participant-specific quartics.
6. `Fig_6_Front_Oblique_Inference.png` - author-selected front-oblique camera/3D illustrative view.

Figure 6 is schematic: avatar locations are not a validated 3D estimate. In the corresponding demonstration protocol, display depth is GT-anchored at selected marker events and interpolated between anchors; quantitative distance metrics use raw quartic predictions at marker events.
